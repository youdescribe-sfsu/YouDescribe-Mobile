# YouDescribe-Mobile

Steps to start the app on your mobile device:
  1. Install the Expo Go app on your phone.
  2. Create an account or Login.
  3. Open a web browser and go to https://expo.dev/@kishan4137/YouDescribe?serviceType=classic&distribution=expo-go
  4. You'll find a QR Code. Scan it using your phone (either on the Expo Go app or using the Camera app) to start the YouDescribe app.
